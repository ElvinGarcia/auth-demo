Level 5: Password + security key

Two factors: something you know, and a hardware-backed key that only signs for the real site.

Educational demo. Use a fake password you have never used anywhere else.
This browser does not support WebAuthn, so this level cannot run here.

No registration. A new username is created the first time you use it, and you then register a security key or passkey for it (Touch ID, Windows Hello, a phone, or a USB key).

Register a security key

Your browser will ask you to create a passkey or insert a security key. The server receives only the public half; the private half never leaves your device.

Use your security key

Approve the prompt with the key you registered for this account.
